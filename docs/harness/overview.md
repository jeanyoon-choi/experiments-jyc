# Harness overview

Six independent Next.js apps share pnpm tooling and a modular Socket.IO relay.
SCC, Goldfishes, six-sigma, and xyt-cube are experimental archives; C-VAL and ddong-meong
are finished artworks maintained within their existing contracts.

[AGENTS.md](../../AGENTS.md) is the operational policy and model/delegation
preference. Read the target app's docs index and follow only relevant links.
[Documentation policy](documentation.md) explains how to keep this harness lean;
[the full map](../README.md) locates reference material.

Runtime pins and verification restrictions belong in AGENTS.md. Setup details:
[Next.js](nextjs.md), [structure](experiments.md), [HTTPS/sockets](https-and-sockets.md),
[deployment](monorepo.md). Theory and dated experiment records are references,
not a mandatory onboarding sequence.
