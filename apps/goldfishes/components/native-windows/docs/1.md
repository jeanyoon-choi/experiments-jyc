## Shared infrastructure

`components/native-windows/shared/` holds what versions 1–3 had duplicated; behavior is unchanged, and the refactor was checked by byte-identical seeded plans, decks, motion frames, AppleScript strings and validation messages against the pre-refactor code.

- `control-server.ts`: `createDesktopControl` — admission (development on macOS, approved local host, same-origin HTTPS JSON), one process slot shared by all versions, NDJSON status, watchdog. Each version's `server.ts` only names its runner and optional status hooks.
- `native-session.mjs`: runner process plumbing — non-overlapping commands with per-version timeouts, osascript, stop on SIGINT/SIGTERM, `runScore` outcome reporting.
- `native-apps.mjs`: the C-VAL Slack deep link, the read-only trial Terminal, and the staged Preview atlas.
- `settings.ts`: seeded random, validation primitives, interval jitter and jump bounds. The order of random draws stays inside each version's `createPlan`, because it defines that version's seeded score.
- `motion.ts`: continuous window choreography (versions 2 and 3).
- `controller/`: polling/start-stop hook, page frame, checkbox group, number fields, run actions and run report, plus the shared stylesheet.

Changing a shared module changes every version that uses it; fork a module into the version when a trial needs to diverge.
