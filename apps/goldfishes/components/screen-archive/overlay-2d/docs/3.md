# 0908 overlay-2d-3

Route: `/screen/overlay-2d/3` (aliases `/screen/0908/overlay-2d-3`, `/0908/overlay-2d-3`). Date: 2026-09-08.

Question: can local sensing, attention feedback and environmental memory produce shifting collective attention without prescribed orbits?

Baseline: complete local copy of overlay-2d-2. Preserve glyphs, surfaces, permanent visible traces underneath opaque keyword circles, and 72 fish at 24Hz. Mutation: bounded local perception, visit habituation, crowding, decaying directional trail sensing, attention-dependent keyword lifetime and propagation. This is an exploratory complex-system model, not an empirically calibrated account of fish or human cognition, nor a demonstrated learning CAS.

Visible traces remain permanent; a separate fixed 64×36 numerical field has an 8-second decay time and influences local motion. Familiarity decays over 12 seconds. These two forms of memory are distinct. No forced circulation or assigned rotation direction. Low-speed self-propulsion maintains exploration. Explicit external arrivals increase with the deficit below 38% new keywords (a replenishment target, not a guaranteed floor); multiple arrivals per tick avoid starving large grids. This regulation is not claimed as self-organized criticality.

Performance revision: target lookup uses IDs, candidate selection queries only nearby grid cells, occupancy storage is reused and familiarity cleanup runs once per simulation second. All non-empty keyword circles are obstacles with a 19px glyph clearance; anticipatory repulsion is backed by bounded projection and inward-velocity removal, including newly appearing circles. Pure default-layout collision checks are not a device FPS measurement or proof for geometrically overcrowded settings.

Memory and trails persist during tab hiding, not full page reload; keyword session restoration remains and has a separate experiment key. Fish and keyword novelty use the same simulation clock.

Validation: Goldfishes typecheck passed. A pure 120-second, 72-fish simulation checked finite in-bounds motion and bounded trail density. Separate assertions checked that out-of-range keywords cannot be selected, moderate contact prolongs a keyword, and crowding shortens it. Browser observation and comparative evidence of collective regimes remain open; no claim of measured emergence or learned adaptation is made.
