# Goldfishes 2d/1

Route: `/2d/1`

Short description: **Glyph swarm and media attention cells.**

This retained 2D branch uses Canvas to draw moving cursor or goldfish agents
around selected grid cells. It includes the two 75-image collage-eye glyph
sets, protected-cell collision, independently staggered media surfaces, and a
bounded media draw schedule.

The experiment owns its complete CPU model, atlas builder, media-source
ledgers, collage renderer, media-cell renderer, screen component, and styles.
It does not import the default experiment's model or media implementation.
