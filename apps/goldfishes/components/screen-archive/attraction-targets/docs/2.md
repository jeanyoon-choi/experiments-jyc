# Goldfishes attraction-targets/2

Date: 2026-08-04 · Route: `/screen/attraction-targets/2` · **Live HTML forms as bidirectional attraction targets.**

Forked from `default`. Each selected cell is a native fieldset: `gather` includes/excludes its target, `pull` changes attraction strength and assigned share, and a meter reports nearby fish. The question is whether an HTML element can be an operational swarm member rather than an image on a target. The form's state drives the model and model observation rewrites the form; removing it removes both control and feedback.

Fish/model behavior, grid footprint, protected perimeter, top orthographic view, orbit/zoom, theme, keyboard selection, sparse field, and collapsed authoring UI remain invariant. Native DOM fieldsets sit in `CSS3DRenderer` with the WebGL orthographic camera; fish remain instanced WebGL. Identity follows grid coordinate: redraw/theme retain it; a resize remapping the anchor creates a new target.

Whether this is compelling in encounter remains unverified. One elementary form is deliberate: an iframe, feed, or video adds cost and content without entering the causal loop.
