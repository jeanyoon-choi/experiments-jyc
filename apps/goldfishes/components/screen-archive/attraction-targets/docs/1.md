# Goldfishes attraction-targets/1

Date: 2026-08-04

Route: `/screen/attraction-targets/1`

Short description: **Tube stations as persistent attraction targets.**

This experiment replaces free selected-cell targets with projected London
Underground stations. The same station coordinates draw the network and define
the swarm targets, making the map operational rather than decorative. Stable
station ordering distributes the default 100 fish across the network, and line
heights become legible when the camera leaves the exact-top view.

The directory contains its own model, Tube snapshot, schematic projection,
renderer, atlas implementations, media-source ledgers, screen, and styles. No
Goldfishes implementation is imported from `default` or another dated trial.
