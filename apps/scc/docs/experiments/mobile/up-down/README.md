# Mobile up-down

Experiments where the mobile's front–back tilt is the peninsula: tipped up, the screen brings out the North; tipped down, the South. Each interface is its own subfamily, `up-down/<interface>/<n>`, as in [left-right](../left-right/README.md). The family began on 2026-11-16.

- [tv-news/1](tv-news.md): the main evening news of both sides as one broadcast; the anchor, her studio and her voice morph between MBC 뉴스데스크 and 조선중앙TV 보도 with the tilt. `/mobile/up-down/tv-news/1`.
