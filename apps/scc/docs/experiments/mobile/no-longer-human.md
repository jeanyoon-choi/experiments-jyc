# 인간 실격

`/mobile/no-longer-human/1` (2026-11-02) is a phone e-book reader at [`/mobile/no-longer-human/[experiment]`](../../../app/mobile/no-longer-human/[experiment]/page.tsx).

- Text: 太宰治『人間失格』(1948, public domain), translated into Korean for this route from the Aozora Bunko text — the full preface (the three photographs) and the first notebook up to the family meal hour, opening with “부끄러움 많은 생애를 보내 왔습니다.” (`model/text.ts`). Every syllable is in KS X 1001, so the Nanum Myeongjo subset copied from `suneung/paper` covers it.
- Page: a cover page (title, author), then each chapter starting on a new page a fifth down. Body 17 px Myeongjo, line height 1.85, justified, 1 em indent, `keep-all`. A quiet running head (chapter title) and page number; both are blank on the cover.
- Pagination: CSS multicolumn, one column per page, pages one viewport width apart; the page count and chapter starts are measured from element positions after fonts load and on resize. Resizing keeps the reading fraction.
- Skating (added the same day): on every page after the cover, a vertical stroke skates the page's letters instead of scrolling. The first stroke reads each visible letter's rect from the typeset DOM (`model/physics.ts`) and covers that page with a canvas of the same letters. Letters stay pinned in type until the finger (38 px reach, dragged along with its velocity, pushed slightly outward) or a letter approaching faster than 0.55 px/frame hits them. Loose letters are circles of 0.46× their advance width: equal-mass collisions (restitution 0.82), the four page edges (0.72), spin from glancing blows, a 40% swell on impact and up to four ink specks per hit; they float with 0.994 damping and a small random drift. A slowly touched pinned letter acts as a wall. Horizontal strokes still turn pages; scattered pages keep their state until a resize, when every page is set in type again.
- Budget: CPU canvas at DPR 1. Letters drifting on their own float at 24 Hz; frames follow the display while a finger is down, a page slides, or letters still carry a push (> 1 px/frame) or specks fly. Reduced motion removes the drift, so loose letters settle and the loop stops. Only the current page is simulated (≈500 letters, ≤160 specks). DPR 1 makes scattered letters softer than the typeset text on high-density screens; raising it needs the device observation the particle safety budget asks for.
- Cost: each letter is rasterised once into a 1024² atlas (`model/render.ts`); a frame is one image of the typeset page, one path papering over the loose letters' typeset boxes, and one `drawImage` per loose letter — no `fillText`. Atlas and page images are immutable `ImageBitmap`s once ready. Physics touches only loose letters, against a pinned grid built once and a typed-array loose grid rebuilt per substep; specks live in a fixed `Float32Array`. A page's letters are read and rasterised 420 ms after it settles, before any stroke. Horizontal drags write the flow transform directly; the typeset book is a memoised component.
- Failure, same day: the first mobile pass drew from a mutable atlas and a mutable pinned-layer canvas, and the user found it slower than the original per-frame `fillText`. Safari re-copies a canvas image source that changed since its last use, and that pass changed both while skating; it also rebuilt a long font-string key per letter per frame. Both were replaced as above.
- Measured (headless Chrome, 390×844 mobile emulation, 6× CPU throttle, five synthetic vertical strokes): median and p90 frame 16.7 ms while skating and after release; longest script task 49 ms. Not measured on an iPhone or in Safari.
- Input: tap the outer 30% on either side or swipe (the finger drags the page; the first and last pages resist), arrow keys. A middle tap slides in reader bars: title and author above, a page scrubber with the chapter and pages left in it below. The reading fraction is kept in `localStorage`.

Static checks only (lint, typecheck); the browser check was blocked by an untrusted localhost certificate, so layout, collision feel and frame rate on a device are unverified.
