# Mobile left-right

Experiments where the mobile's tilt is a political lean: rolled left, the screen brings out 좌파; rolled right, 우파. Each interface is its own subfamily, `left-right/<interface>/<n>`. The family began on 2026-11-16, when `mobile/kakao-talk` moved in as its first member.

- [naver-news/1](naver-news.md): Naver News's 정치 section, whose headline rows turn over into the tilted side's reading, from slanted reports to 사설 to fandom media; any piece opens as an article page. `/mobile/left-right/naver-news/1`.
- [kakao-talk/1](kakao-talk/README.md): a KakaoTalk whose chat rooms drift toward 진보 or 보수 as the mobile rolls, each room in its own register, then harden to 극단 as dissenters leave. `/mobile/left-right/kakao-talk/1`.
